Why does it wrap?

An N-bit signed integer has only 2N possible bit patterns. For an 8-bit signed integer, those patterns represent -128 through 127.

What happens at the edge?

When the mathematical result is outside the representable range, the bit pattern can wrap around. For example, 128 becomes -128 in an 8-bit two's-complement model.

Educational model: this demonstrates fixed-width two's-complement wraparound. Actual language behavior can differ; for example, signed overflow in Java is defined to wrap, while signed integer overflow in C/C++ has important language-specific rules.
